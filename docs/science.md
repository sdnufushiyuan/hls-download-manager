# 科学口径与断点

- 数据源：`NASA/HLS/HLSL30/v002`和`NASA/HLS/HLSS30/v002`，按每次观测保存，不做月/年时间合成。
- L30使用B4/B5/B7；S30使用B4/B8A/B12。程序的反射率乘数默认1，针对EE目录的值；不得套用原始COG的比例后再次缩放。
- 输出red、nir、swir2、NDVI、STR、Fmask，30米米制投影。`NDVI=(nir-red)/(nir+red)`；`STR=(1-swir2)^2/(2*swir2)`，分母无效的像元剔除。
- Fmask位1–5须均为0；默认只接受低气溶胶，另有显式climatology-low选项。NoData为-9999，各波段掩膜一致。
- 去重仅限同一传感器和完全相同`system:time_start`的重叠覆盖；不同时间/不同传感器保留。检查采用同一30米网格，不使用粗分辨率替代。
- 输出小块先临时写入、检查、无损压缩、计算SHA256，再提交；完整景在所有必需块成功后才写完成记录。`.part`不计为完成。
- 断点不仅检查文件存在，还核对配方、选择规则、SHA256、网格、波段、NoData和质量。不能靠手工创建scene.json把未完成的数据标成完成。
- 候选完成数包括新下载、有效缓存复用和合法跳过。冻结库存是计数参考，不是已下载字节；归档最终完成还需服务正常结束。

研究结论仍需在自己的ROI/时段上验证HLS质量、区域覆盖与后续OPTRAM建模假设。本仓库负责输入档案与运行管理，不包含完整土壤水分反演训练和结果评估。
